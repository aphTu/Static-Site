# Static-Site
Generating a Static Site using Python

## Usages
The program takes in markdown files in the content folder and generate a site using the template.sh. 
To add images, include them in the static/images folder
To change styling, modify the included index.css file
Once you are satisfy with the changes, run the build.sh to generate the files into the docs folder, since github uses /docs folder to publish the site.
